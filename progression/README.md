# 寻王 · 主城与地图试玩

- 主城选择 1～5 名角色，然后选图。地图标注推荐等级，只有打完前一张地图才开放下一张。
- 九张地图复用现有素材。每关 2～4 波，部分波次有精英。推荐 10 和 20 级的地图各在最后一波出现头目。
- 中途每波结算后可以查看背包、回城或手动开始下一波。通关和失败均会结算，8 秒后回城。打开背包会暂停回城计时。战斗中可从「试玩统计 → 回城」结束本次挑战。回城保留已取得的经验和战利品，背包已满时，地面未拾取的装备会留在关卡内。
- 六名角色使用同一套裸装基础数值表。每个角色单独保存等级和经验，活着的上阵角色分各自经验。死亡扣除本级所需经验的 5%，本级经验最低为 0，等级不降低。
- 旧共享存档将原共享等级和经验作为各角色的迁移起点。旧版按等级解锁的地图没有通关记录，新规则从第一张图开始记录。装备、背包和无尽记录继续保留。
- 体修、战士、剑修具有较高仇恨系数，持续输出可从其他角色处拉走怪物。追击时优先选择正在锁定自己的最近怪物，已交战且目标仍在射程时保持当前目标。
