# 寻王 · 1～20 级成长试玩

- 首次开局建立独立试玩存档。从 1 级、三件白装开始，出战可在六名基础角色中选择 1～5 人。继续沿用青石村场景和现有素材。
- 闯关按 1、3、5、8、10、13、15、17、20 级开放九关。小队共享经验，击杀才增加经验。当前关打完但下一关尚未开放时，可继续在当前关积累经验。
- 选择关卡不改变队伍等级。无尽以进场时的队伍等级为起点。20 级封顶。
- 词条和技能从原有 v1.5 池独立试洗。打开装备详情选择「洗练」，再点选要重抽的条目。本版免费试洗，吞噬入口移除。
- 火、冰、雷、毒、暗五种固定属性石。防具提供对应抗性 10%，首饰提供对应伤害 +10%。武器按首颗属性石转换攻击属性。伤害颜色区分属性，暴击额外放大。
- 掉落仍走原品质权重。在「试玩统计」可随时在正常 1.0 倍和试玩 2.0 倍之间切换。试玩倍率可通过 `data/config.json` 的 `progression.drop_multiplier` 修改。品质名保留，橙为暖铜、红为绛红、暗金使用亮金。
- 怪物按等级、类型和出阵人数调整。两小时是首轮节奏目标，编队、装备、重试和手动整理会影响时间。
